# Testando
Para testar siga estes passos:

### Crie um venv na pasta raiz do projeto:
```
python -m venv .venv
```
### Abra o terminal, ative o venv:
Use o comando: `.venv/Scripts/activate`.

É possível também configurar o python no vs code para usar o venv automaticamente como interpretador. Veja as configurações do python no VSCODE.

### Instale o luupy2d no venv em modo editável:
```
pip install -e .
```
(**não esqueça do ponto! '.' no final do comando**)

### Pronto!
Teste usando o comando `luupy2d` no terminal!
